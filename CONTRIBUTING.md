# Contributing to ShoukakuDocs

Public documentation corrections and improvements are welcome.

## Scope

Appropriate contributions include:

- correcting inaccurate public documentation;
- improving clarity, accessibility, grammar, or navigation;
- documenting public behavior that matches the official hosted Service;
- fixing broken public links;
- improving privacy, security, copyright, or safety wording without overstating legal compliance.

Do not submit:

- credentials, tokens, cookies, private endpoints, internal IP addresses, or secrets;
- production logs, database records, personal data, or vulnerability details;
- proprietary backend code copied from a private repository;
- third-party text, images, or trademarks that you do not have permission to contribute;
- documentation that claims a feature is enabled when the backend does not match it.

## Contribution Certification

By submitting a pull request, commit, issue text, or other contribution, you certify that:

1. you created the contribution or have the right to submit it;
2. the contribution does not knowingly violate another person's rights;
3. you grant the repository owner a perpetual, worldwide, non-exclusive, royalty-free right to use, reproduce, modify, publish, distribute, and relicense the contribution as part of Shoukaku and its documentation;
4. you understand that the public repository is governed by [LICENSE](LICENSE), not by an open-source license.

## Review

The Operator may edit, reject, close, or remove contributions for accuracy, security, legal, privacy, brand, or maintenance reasons.

Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not a public pull request.
